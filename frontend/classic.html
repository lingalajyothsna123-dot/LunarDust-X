How It Works

  1. InputYou enter rover speed and surface slope.
  2. ValidateThe page and the API check the allowed ranges.
  3. RequestJavaScript calls the FastAPI /predict endpoint.
  4. PredictThe saved Decision Tree model classifies the input.
  5. DisplayResult, risk level and charts update on screen.

Project Information

  • Title: Intelligent Lunar Dust Prediction and Monitoring System
  • ML: Decision Tree Classifier (scikit-learn)
  • Backend: FastAPI + Uvicorn
  • Frontend: HTML, CSS, JavaScript, Chart.js
  • Data: simulated records (1000 rows)

About the Project

LunarDust-X is a college-level machine learning prototype that shows how rover movement could influence dust on the lunar surface. Because the dataset is simulated, results are for learning and demonstration only and must not be used for real mission decisions.
